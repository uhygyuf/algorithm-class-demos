📐 Formulas

Hash function:  h(key) = key % TABLE_SIZE  (TABLE_SIZE = 10, indices 0–9)
Linear probing:  index = (index + 1) % TABLE_SIZE ← scan the next slot on collision (wrap from 9 back to 0)
Search stop rule:  an EMPTY slot means the key is absent; if we loop back to start, it is absent too
