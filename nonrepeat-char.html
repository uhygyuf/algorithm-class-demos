💡 The idea the problem asks for a hash table

Why two passes? In one pass you cannot know whether a character repeats later → count everything first, then search.
● Hash: only 26 letters → use array count[26]; index c − 'a' is the "hash address" (O(1) read/write). More generally you may use map<char,int>.
● Pass 1: for each character count[c − 'a']++.
● Pass 2: scan again in the original order; output the first count == 1 and stop. If none qualifies → print None.
